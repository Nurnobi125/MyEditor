# Security policy

## Supported versions

Security fixes are made for the latest supported version of MyEditor. Older releases may not receive updates.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's **Report a vulnerability** feature on the repository's Security tab if private vulnerability reporting is enabled. If it is not available, contact the repository owner privately through their GitHub profile and include steps to reproduce the issue. Avoid sending private media or project files unless they are essential and you have removed personal information.

Please include the affected version, Windows version, impact, and a minimal reproduction. You should receive an acknowledgement when the report is reviewed.
