# MyEditor 3.3 - Advanced screen recorder

## Full video templates
- Six ready-made 15-second, three-scene video starters in Templates: Neon product promo, Cinematic brand story, Creator intro, Quick tutorial, Event announcement and Travel story.
- Each template builds its background scenes, animated title text and animated shape accents directly on editable timeline tracks.
- The headline comes from the title field; all timeline text can be changed after creation. The app asks before replacing an existing edit and keeps imported media available.

New
- Recorder Studio (Settings menu): quality, encoder, resolution, fps, system audio, webcam, countdown, auto-stop, cursor.
- Hardware H.264 encoders (NVENC / Quick Sync / AMF) with automatic CPU fallback.
- Microphone + system audio mixed into a single track.
- Webcam picture-in-picture (corner, size, mirror).
- Crash-safe fragmented segments, joined losslessly on stop.
- Live file size / dropped frames / encoder in the recording control bar; automatic stop if capture ends unexpectedly.

- Premium emoji pack: 5 categories (Love, Hype, Glam, Money, Social) x 8 emoji x 6 metallic finishes (Gold, Rose Gold, Platinum, Royal, Emerald, Ruby) x 10 motions = 2,400 new stickers (6,960 total).
- Premium text templates: 12 styles x 5 variants (Gold luxe title, Royal intro, Diamond lower third, Glam caption, VIP badge, Rose gold quote, Platinum headline, Luxury sale, Cinema credits, Neon pink hook, Crown outro, Elite name tag) in a new "Premium" gallery category.
- New text colours: Gold, Pink, Violet (preview and export).

- Animated backgrounds: 540 looping motion backgrounds (Color flow, Drift, Swirl, Breathe, Shimmer) rendered once to MP4 with FFmpeg filters.
- Shapes & Backgrounds studio (top bar, "Shapes"): 513 premium shapes and 108 background designs, drag and drop onto the timeline or preview, with motion and duration presets.

Changed
- Audio is recorded as AAC 160 kbps / 48 kHz (was 96 kbps / 44.1 kHz).
- Recording mode in the toolbar still works; Recorder Studio overrides resolution/fps only when you choose a value.

Notes
- Webcam and system audio require DirectShow devices that FFmpeg can see.
- Window-capture mode records only that window, as before.
